# 领养一颗大脑 | Adopt a Brain

《领养一颗大脑》是一款在浏览器中运行的互动选择游戏。你会领养并命名一颗虚拟大脑，在日常事件中作出选择，观察这些选择如何改变游戏中的脑区活跃度、情绪指标和脑型。

这里展示的是游戏化的规则模型，不是真实或经过科学验证的大脑模拟器。

## 在线游玩

> **在线版本尚未发布。** GitHub Pages 当前没有可验证的公开页面；项目维护者启用后，可直接在浏览器中游玩。

普通玩家无需下载源代码。维护者可按[开发文档](docs/DEVELOPMENT.md#部署到-github-pages)中的步骤启用 GitHub Pages。

## 怎么玩

1. 为你的虚拟大脑取一个名字并开始游戏。
2. 等待生活事件出现，从三个应对方式中选择一个。
3. 查看模拟脑区活动、情绪箭头和可视化图像随选择变化。
4. 累积完成事件，观察你的脑型：每完成 10 个事件，游戏会重新计算一次脑型，因此它可能随游戏进程改变。

## 界面说明

- **侧视激活图与轴位脑区图**：用颜色变化表现七个游戏化脑区的当前活跃度。
- **模拟脑电（EEG-style）**：根据当前状态生成的动态波形，并非脑电测量结果。
- **模拟功能成像（fMRI-style）**：以热力图方式表现活动变化，并非真实扫描图像。
- **情绪指标**：愉悦、压力、动力、专注、记忆、社交、创意和流畅；箭头表示近期变化方向。
- **脑型**：完成至少 10 个事件后出现，之后每 10 个事件更新一次。
- **数据统计**：显示游玩时长、已完成事件数、峰值指标、最活跃脑区和累计激活。

## 九种脑型

脑型由游戏期间累积的选择决定，之后仍可能改变。它们只是虚构的游戏分类，不代表人格测验或医学结论。

| 脑型 | 游戏中的特点 |
| --- | --- |
| ⚙️ 齿轮脑 Gear Brain | 习惯建立后执行高效，但面对新情况较不灵活。 |
| 🐚 贝壳脑 Shell Brain | 偏好固定程序，对变化保持警觉。 |
| 🪨 基岩脑 Bedrock Brain | 稳定、耐压，但弹性较少。 |
| 🔥 熔炉脑 Furnace Brain | 情感与行动力强，对奖励敏感。 |
| 🌊 深海脑 Deep Sea Brain | 情感和记忆细节丰富，较容易内耗。 |
| 🌿 根系脑 Root Brain | 情绪稳定，重视关系和长期积累。 |
| ⚡ 电弧脑 Arc Brain | 分析后快速行动，目标导向明显。 |
| 🔬 显微脑 Microscope Brain | 专注于分析各种可能，行动较谨慎。 |
| 🌐 网络脑 Network Brain | 在分析与感受之间保持较均衡的状态。 |

## 保存与重新开始

- 游戏使用当前浏览器的 `localStorage` 自动保存：每次作出选择后保存一次，游玩时也会每 30 秒保存一次。
- 使用同一浏览器再次打开同一网址时，游戏会自动读取并继续之前的进度。
- 如需重新开始，点击左侧数据栏底部的“回到菜单 / Back to Menu”两次确认，再选择“重新开始 / New Brain”。
- “重新开始”和“清除存档”都会先显示确认提示；确认后，当前本地存档会永久删除。
- 清除浏览器网站数据、使用隐私浏览，或更换浏览器、设备、域名，都可能让存档不可见或被删除。

本游戏不提供账号、云同步或存档导出。

## 重要说明

脑区活动和情绪变化由简化的规则计算。EEG/fMRI 风格图像完全由程序生成，不是实际测量；脑型也是虚构分类。游戏中的脑区分层、情绪和行为关系均为玩法抽象，不应用于心理诊断、医疗评估、人格判断或真实认知能力测量。

## 常见问题

**如何开始？**
在线版本发布后，用现代浏览器打开页面，为大脑命名并点击“开始 / Start”。

**为什么还没有脑型？**
第一次脑型计算发生在完成第 10 个事件后。

**为什么脑型没有改变？**
脑型只在每 10 个事件时重新计算，而且当累积选择仍落在同一分类中时会保持不变。

**如何继续上次游戏？**
在保存进度的同一浏览器中重新打开同一网址，游戏会自动恢复。

**如何重新开始？**
从游戏的数据栏进入菜单，选择“重新开始”；确认后旧存档会被删除。

**进度保存在哪里？为什么另一个浏览器里没有？**
进度仅保存在当前浏览器、当前网站的本地存储中，不会跨浏览器或设备同步。

**支持哪些设备？**
游戏使用 JavaScript 模块、Canvas 和本地存储，需要较新的 Chrome、Edge、Firefox 或 Safari。页面会在窄屏上改为纵向布局；由于可视化信息较多，桌面或较大屏幕体验更完整。

技术架构、数据格式与本地运行方式见[开发文档](docs/DEVELOPMENT.md)。
